Transcription benchmark · German interview · 65 min 45 s

Sinribe vs Vibe vs
stock large-v3

One 66-minute German coaching interview, transcribed three ways and scored word-by-word against a human transcript. Same audio, same reference, same scoring code. The third transcript is a neutral baseline: stock faster-whisper large-v3, run for this benchmark by Claude Code (an AI coding agent), with no diarisation or post-processing.

Result: Sinribe leads on every axis measured — word accuracy, meaning-changing errors, timestamps, and speaker attribution.

Scorecard

Three systems, 9,174 reference words

Word error rate counts every substitution, deletion and insertion against the human transcript. Lower is better. The human transcript is lightly cleaned prose, so a few points of every score here are style, not mistakes — that penalty falls on all three equally.

Word accuracy

Sinribe makes the fewest errors of any kind

Against 9,174 human-transcribed words, Sinribe's word error rate is 18.84% — an 8.1% relative reduction against Vibe and 6.6% against a stock large-v3 run on the same GPU.

What the errors actually are

Not all errors cost the reader something

Every difference was classified automatically. Cosmetic errors preserve meaning — gern/gerne, a dropped ja, a swapped article, or two spellings that sound identical under German phonetics (Kölner Phonetik). Substantive errors change the word a reader takes away — Fieber → Führer, Trance → Branche. That second number is the one worth optimising.

Speaker attribution

Only Sinribe answers "who said this?"

Vibe and the stock baseline emit an undifferentiated stream of text. For an interview, where the whole point is separating the interviewer's questions from the subject's answers, that is the difference between a transcript and a wall of text.

Detail

The interviewer speaks only 11% of the hour — the hard case for diarisation, because a system can score well by ignoring them entirely. Sinribe still recovers 97.7% of their words, and correctly maps both roles with no manual hint.

Shape of the output

160 speaker turns, or 929 fragments

Method & caveats

How this was measured

Reference

Manual-transcript.docx, 9,174 words after normalisation, treated as ground truth. Stage directions and Unverständlich markers were stripped before scoring.

Scoring

Exact word-level Levenshtein alignment with backtrace. Text is lower-cased, punctuation and quote marks removed, umlauts preserved. Identical code path for all three systems.

Stock large-v3 baseline

Stock faster-whisper large-v3, run for this benchmark by Claude Code (an AI coding agent), float16 on the RTX 5070 Ti, beam 5, VAD on, language forced to German. 65 min of audio in 139 s (28× real time). One pass, no diarisation, no post-processing.

Shared base model

The stock baseline and Sinribe both build on large-v3. The gap between them is therefore attributable to Sinribe's pipeline — multi-pass voting, segmentation and diarisation — not to a different underlying model.

The reference is not perfect

The human transcript has two out-of-order timestamps near the end; timing was measured only over its monotonic span (first 8,847 words). It also condenses speech in places, which charges every ASR system for words that were genuinely spoken.

What this does not measure

Speed and cost. Sinribe's own header reports its run as served from cache, so no like-for-like throughput comparison was possible here.
